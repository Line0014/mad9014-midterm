Event Loop

Async, Events, Promises

JS has an event loop for each execution context. The global scope and each function are execution contexts.

The event loop runs the code that is added to the main stack. Each time the stack completes it checks for microtasks, then tasks, then UI Render tasks that need to be completed.

Once it starts running microtasks it will run all of them that are in the microtask queue.

Tasks will be run one at a time, with another pass around the event loop to check if there is new code on the main stack between each task.

UI Render tasks get run as the JS engine feels they need to be run, but typically it happens after microtasks and the top task is done. They will be run as the JS engine goes around the loop completing the main stack. It could run a UI Render task after each item on the main stack, if it wants.
